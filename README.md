# P14s Sway Dotfiles

Personal Sway configuration for my Lenovo ThinkPad P14s running Ubuntu 26.04 LTS.

## Goals

- Lightweight Wayland desktop
- Keyboard-first workflow
- Laptop-friendly controls
- Development and data-science workstation
- Remote work with DGX Spark
- Reproducible configuration stored in Git

## Components

- Sway
- Waybar
- Wofi
- Swaylock
- Swayidle
- Foot terminal

## Status

Stage 1: Basic Sway environment working.
